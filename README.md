# Gamepad Tester

A lightweight React + Vite app that uses the browser Gamepad API to visualize controller input in real time.

This project is designed to help you inspect connected gamepads, including button presses, analog stick movement, controller mapping, and device metadata. It includes a stylized controller visualizer inspired by DualSense hardware.

## Features

- Detects and displays connected gamepads
- Shows per-button pressure values and pressed state
- Visualizes left and right stick axis movement
- Displays controller index, mapping, timestamp, and connection status
- Uses a modern browser-based interface with no backend required

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
